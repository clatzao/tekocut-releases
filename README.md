# TekoCut

Editor de vídeo para Windows que guarda tudo no seu computador: sem conta, sem plano e sem créditos.

Este repositório guarda só os **instaladores e as atualizações automáticas**. O código-fonte é privado.

## Instalar

1. Em [Releases](https://github.com/clatzao/tekocut-releases/releases/latest), baixe o `TekoCut-Setup-<versão>.exe`.
2. Abra o instalador. Como ele não é assinado, o Windows pode mostrar "O Windows protegeu o computador". Clique em **Mais informações** e depois em **Executar assim mesmo**. Isso só acontece na primeira instalação.
3. Escolha a pasta. O instalador cria atalhos na área de trabalho e no menu Iniciar.

## Atualizações

O TekoCut procura versões novas ao abrir e a cada 6 horas. Quando há uma, ele a baixa em segundo plano e mostra **Reiniciar**; o projeto aberto é salvo antes. Em Configurações > Geral você vê a versão instalada e pode procurar atualizações na hora.

Só o instalador é baixado deste repositório. Nada seu é enviado.

# What comes with TekoCut from others

Everything else that comes with TekoCut was made for it: the effects, transitions and animations
(`content/packs/tekocut.tekopack`), the filters, the text styles, the stickers and the sounds.

## Fonts

The fonts are from [Google Fonts](https://fonts.google.com), through the [Fontsource](https://fontsource.org) packages.
Each one is under the SIL Open Font License 1.1 (OFL-1.1), the Apache License 2.0 or the Ubuntu Font Licence 1.0, as
listed. All three allow using and bundling them in an app. The licence text is in each package (`node_modules/@fontsource/<name>/LICENSE`).
